# QR 메뉴판 UI 개편 — 설계

- 날짜: 2026-09-15
- 대상: koreanbbqstore.com (강남 돼지상회 무한리필, 13개 언어 정적 사이트)
- 브랜치: `fix/site-audit-2026-09` 위에 새 브랜치로 진행

## 1. 배경과 목표

이 사이트는 **테이블에서 QR을 찍고 보는 메뉴판**이다. 지금은 메뉴와 가격이 전부 버튼 뒤에 숨어 있어, 자리에 앉은 손님이 코스 하나를 보려면 탭을 해야 하고 셋을 비교하려면 세 번 탭·닫기를 해야 한다.

목표는 하나다: **첫 화면에서 스크롤 한 화면 반 안에 코스 3개의 가격과 구성, 사이드 가격이 탭 없이 보인다.**

사용자가 공감한 문제 (8개 중 7개):

| # | 문제 | 해결 구역 |
|---|---|---|
| ① | 첫 화면에 메뉴도 가격도 없다 | 코스 카드, 사이드 표 |
| ③ | 빈 공간이 크고 스크롤이 길다 | 히어로 삭제, 접이식 |
| ④ | 언어 바꾸기가 멀다 | 상단 고정 바 |
| ⑤ | 음식 사진이 없다 | 이모지 앵커 (사진은 당분간 없음) |
| ⑥ | 상세 내용이 한 줄에 빽빽하다 | 구분자·줄바꿈 |
| ⑦ | 주문·리필 방법이 숨어 있다 | 벨 안내 띠 |
| ⑧ | 히어로가 너무 크다 | 히어로 삭제 |

② "버튼이 다 똑같다"는 사용자가 문제로 보지 않아 제외.

| 항목 | 결정 |

## 3. 화면 구조 (위→아래 6구역, 모바일 기준)

### ① 상단 고정 바
- `position: sticky; top: 0`. 빨강 배경, 흰 글자.
- 왼쪽: 로고(`images/logo.png`, 28px) + 매장명. 매장명은 기존 히어로 `h1` 13개 언어 문구 재사용.
- 오른쪽: 언어 버튼 `🌐 한국어 ▾`. 글자는 `LANG_NAMES[현재 언어]`. 누르면 기존 언어 모달.
- 히어로 섹션(로고 큰 것 + 슬로건 + Change Language 버튼)은 **삭제**. 슬로건 13개 언어는 푸터 © 줄 위로 이동.

### ② 벨 안내 띠
- 노란 배경(#fff3cd) 한 줄: 🔔 + 문장. 항상 보임, 접히지 않음.
- 유일한 신규 문구. 13개 언어:

| 언어 | 문장 |
|---|---|
| ko | 주문·리필은 테이블 벨을 눌러주세요 |
| en | Press the table bell to order or get a refill |
| zh | 点餐或续餐请按桌上的呼叫铃 |
| ja | 注文・おかわりはテーブルのベルを押してください |
| vi | Bấm chuông bàn để gọi món hoặc lấy thêm |

### ③ 코스 카드 3장 (항상 펼침)
- 섹션 제목: 기존 `h2` "메뉴 소개" 13개 언어 재사용.
- 카드 = 흰 배경, 연핑크 테두리, 둥근 모서리. **Full 카드만** 빨간 테두리 + 연한 배경으로 강조하고, 하단에 이모지 칩 `🍗 🥤 🍚 🍜`(글자 없음, `aria-label`만).
- 카드 헤더: 왼쪽 `코스 라벨(.course-label) + 제목`, 오른쪽 `가격 줄`. 본문: 구성.
- 카드 앞 이모지 앵커: A·B `🥩`, Full `🥩` (본문 칩으로 차별화).
- 콘텐츠 원본은 `CONTENT.courseA/B/F[lang]` 그대로. 자르는 규칙은 §4.
- 기존 상세박스 열고 닫는 동작은 코스·사이드에서 **제거**(항상 펼쳐져 있으므로).

### ④ 사이드 가격표 (항상 펼침)
- 섹션 제목: 기존 사이드 메뉴 버튼 라벨 13개 언어 재사용.
- 한 줄 = `이름 (설명) ······ 가격`. 이름 왼쪽, 가격 오른쪽 빨강 굵게. 줄 사이 점선.
- 원본은 `CONTENT.side[lang]`. 자르는 규칙은 §4.

### ⑤ 접이식 안내 4개
- 이용방법 · 코스별 이용팁 · 가마솥 유래 · 한국식 쌈. 라벨은 기존 버튼 문구 13개 언어 재사용.
- 헤더는 `<button>`(전체 너비, 오른쪽 ▾). 누르면 아래에 기존 상세박스가 열린다. **한 번에 하나만** 열림, 다시 누르면 닫힘 — 현재 `openDetail` 동작 그대로.
- 가마솥·쌈 박스의 배경 이미지와 스타일은 유지.

### ⑥ 푸터
- 순서: 슬로건(히어로에서 이동) → © 브랜드 → 3개 지점 카드(현재 그대로).
- 지점 링크 행("강남본점 / 홍대직영점 / 명동직영점")은 지점 카드와 중복이므로 **삭제**.
- 향후 QR을 지점별 URL(`?store=hongdae`)로 만들면 그 지점 카드를 맨 위로 올릴 수 있도록 카드에 `id="store-<지점>"`을 유지한다(이미 있음). 이번 범위에서 URL 처리는 하지 않는다.

### 언어 선택 전 상태
- 지금은 언어를 고르기 전 본문을 숨긴다(`hidden-body`). 개편 후에는 **본문을 한국어로 그대로 보여주고 모달만 위에 띄운다.** 모달 배경이 어둡게 깔리므로 가려짐. `hidden-body` 클래스와 관련 CSS는 삭제.
- 저장된 언어가 있으면 모달 없이 그 언어로 시작(현재와 동일).

## 4. 콘텐츠 자르기 규칙 (문구 무변경의 핵심)

`content.js`의 코스 블록 39개(3코스 × 13언어)는 모두 같은 뼈대다:

```
<span class="menu-subtitle">…제목…</span>
…가격 줄(텍스트 + <span class="price">{{토큰}}</span> + 텍스트)…<br>
…구성(텍스트, <span class="small-note">(…)</span>, <span class="small-note">+</span> 구분자, courseF는 <br> 포함)…
```

**코스 카드 렌더** — 블록 HTML을 임시 요소에 넣은 뒤 DOM으로 나눈다:
1. `.menu-subtitle` 요소 → 카드 제목 칸으로 이동.
2. 남은 노드 중 **첫 `<br>` 이전** 노드 전부 → 가격 칸. (언어별 어순 "1인 17,900원" / "₩17,900 per person"이 그대로 보존된다.)
3. 첫 `<br>` 이후 노드 전부 → 본문 칸.
4. 본문의 `<span class="small-note">+</span>`는 클래스를 `.sep`으로 바꾸고 CSS로 ` · `처럼 보이게, 줄바꿈 허용. 다른 `.small-note`(재료 괄호)는 그대로.
5. 가격 토큰 치환은 지금처럼 `fillPrices(block, lang)`를 먼저 적용한다.

**사이드 표 렌더**:
1. `.menu-subtitle`(“사이드메뉴”)는 버린다 — 섹션 제목이 따로 있다.
2. 남은 노드를 `<br>` 단위로 줄로 나눈다. 빈 줄은 건너뛴다.
3. 줄마다 `.price` 요소를 찾는다. 있으면 `이름 = price 앞 노드 전부`, `가격 = price + 그 뒤 노드 전부`(“per person” 같은 꼬리말이 가격 옆에 붙는다). 없으면 그 줄은 이름 칸에 통째로.

**폴백** — 코스 블록에 `.menu-subtitle`이 없거나 `<br>`이 없으면 자르지 않고 블록 전체를 카드 본문에 넣는다. `console.warn`으로 어느 블록인지 남긴다. 화면이 깨지지는 않는다.

**언어 전환** — 카드·표는 13개 언어 버전을 전부 렌더해 두고 `data-lang` + `hidden`으로 현재 언어만 보인다(상세박스와 같은 방식). 언어를 바꿔도 다시 그리지 않는다.

**아랍어(RTL)** — `<html dir="rtl">`이 이미 적용되므로 카드 헤더·가격표의 flex는 자동 반전된다. 가격 칸 정렬은 `text-align: end`로 쓴다.

## 6. 합격 기준

구현이 끝났다고 말하려면 아래가 전부 ○여야 한다.

1. **가격까지 0탭** — 390px 폭에서 페이지를 열고 스크롤 없이 A코스 가격, 한 화면 반 안에 Full 가격과 사이드 첫 항목이 보인다.
2. **문구 무손실** — 13개 언어 × (코스 3 + 사이드 1 + 접이식 4) 렌더 텍스트의 토큰 집합이 개편 전과 같다. 허용되는 차이는 `+` 구분자 → ` · ` 뿐. 가격 값 불일치 0.
3. **언어 전환** — 13개 언어 각각에서 보이는 `data-lang` 요소가 그 언어뿐이고, 상단 바 버튼 글자가 그 언어 이름이다. 아랍어에서 가격이 왼쪽 끝에 온다.
4. **접이식** — 4개 헤더가 키보드(Tab·Enter)로 열리고 닫히며, 한 번에 하나만 열린다.
5. **첫 방문·재방문** — 저장 언어 없으면 모달 + 뒤에 한국어 본문, 있으면 모달 없이 그 언어.
6. **콘솔 오류 0**, 1280/390 스크린샷에서 겹침·잘림 없음.
7. `content.js`·`prices.js` diff가 비어 있다.
